# Soni 3D Studio

Офлайн PWA барои ҷамъоварии аксҳои чандтарафа, сохтани модели ибтидоии low-poly, дидани он ва содироти OBJ/GLB.

## Муҳим — маҳдудияти ин версия
Ин версия фотограмметрияи ҳақиқӣ намекунад. Аксҳо ҳамчун истинод нигоҳ дошта мешаванд; геометрияи мошин/объект аз андозаҳои танзимшаванда сохта мешавад. Барои барқарорсозии воқеӣ аз аксҳо муҳаррики photogrammetry/AI-и махсус лозим аст, ки аз браузери оддӣ ва телефон вазнинтар аст. GLB/OBJ-и содиршуда модели ибтидоии геометрӣ аст, на нусхаи дақиқи объект.

## Оғоз
- Барои санҷиш: сервери маҳаллӣ ё GitHub Pages-ро як бор кушоед, баъд service worker нигоҳ медорад файлҳоро офлайн.
- Барои насби PWA: сайт бояд тавассути HTTPS ё localhost кушода шавад.
- Дар Android: Chrome → меню → Add to Home screen.

## Истифода
1. Аксҳои пеш, қафо, чап, рост, боло ва ҷузъиётро илова кунед.
2. «Сохтани модел»-ро пахш кунед.
3. Андозаҳои тахминиро танзим кунед ва моделро бо ангушт гардонед.
4. OBJ ё GLB содир кунед.
5. «Захира кардани лоиҳа» барои нигоҳ доштани параметрҳо дар ҳамин браузер.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Android APK бо GitHub Actions
Workflow дар `.github/workflows/android.yml` веб-файлҳоро ба Android WebView wrapper мегузорад ва APK месозад. APK-ро аз Actions → Artifacts мегиред. Барои насби мустақими APK аз вебсайт, домени махсус шарт нест.

## Технология
HTML, CSS, JavaScript, Canvas 2D projection, PWA Service Worker, Android WebView.
